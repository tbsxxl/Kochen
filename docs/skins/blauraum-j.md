# Blauraum – Entwurf J „Dünn und fett“ (Dez. 2026)

Gewählt vom Besitzer aus zehn Entwürfen (bencium-innovative, Runde 1, nur Schrift/Farbe/Abstand). Der 3D-Raum bleibt.

- **Idee:** Host Grotesk („Skin Raum“) in zwei Gewichten im selben Satz – 200 für den Fluss, 800 für das, was zählt.
- **Farben:** Blau `#0C0CD6`, Weiß, Gelb `#F4F000` nur für „Alle Rezepte“ (und wie bisher aktiver Reiter/Zeiger).
- **Startseite** (`.blJ` in `blauraum.js`, nach dem 3D-Raum): Name · Datum winzig versal, „Heute für dich“, dann ein Satz:
  **Name**, Untertitel dünn mit fettem letztem Wort. Zeit winzig, Kategorien als „**Hähnchen** 29“, „Alle n Rezepte“ gelb.
  Die Karte „Heute für dich“ ist dann ausgeblendet.
- **Überall:** Seitentitel dünn, Rezeptnamen auf Karten fett.
- **Rezeptseite:** Name (800) und Untertitel (200) laufen als ein Satz mit Komma und Punkt.
- **Kochmodus:** Blau, Schritt dünn und groß, Zeiten/Mengen/Timer fett, Beschriftungen winzig versal, Weiter weiß mit blauer Schrift.
