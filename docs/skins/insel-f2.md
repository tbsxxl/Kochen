# Die Insel – Richtung F2 „Funkspruch“ + Countdown aus C2 (ROUND-2-CONTEXT, vom Besitzer gewählt, Dez. 2026)

Entstanden mit `bencium-innovative-ux-designer`: A–J → „C, D, F“ → Feinrunde C2/D2/F2 → „F2, aber irgendwie C2 reinbekommen“.
Die Insel = Lost-Welt, ohne Namen, Figuren, Logos, Zitate, Originalschrift und ohne die bekannte Zahlenfolge.

## Grundgedanke
Ein Funkspruch, der seit Jahren in Schleife läuft (Wiederholungen werden schwächer) – und alles, was mit Zeit zu tun hat, leuchtet in
Bernstein wie der Rechner im Bunker.

## Festgelegt
- Fast schwarzes Grün `#07100C`; Funk-Grau `#E4EEE8` / `#9DB5AA` / `#7A9888` (alle ≥ 4,5 : 1); Echos `#4F6A5C` / `#3F5649` nur als Schmuck
  (aria-hidden); Bernstein `#FFB547` für Countdown, Zeiten, Timer, Kochen/Weiter.
- Share Tech Mono versal gesperrt („Skin Funk“) für Namen/Beschriftungen, VT323 („Skin Bunker“) für die Countdown-Zahlen, Systemschrift für Lesetext.
- Startseite `.isRadio` (`insel.js`): Name · Datum, Kochdauer des Tagesgerichts als riesiger Bernstein-Countdown (`clock()`: „ca. 5 Std“ → 5 STD,
  „1 Std 30 Min“ → 1:30 STD), „Heute für dich“, Name + drei schwächer werdende Echos, Untertitel, Kategorien in drei Helligkeiten, „Alle n Rezepte“ + Echo.
- 3D-Insel unter dunklem Schleier. Keine Karten, keine Sofortbilder/Glutkanten mehr. Kochmodus dunkel, Zeiten/Timer/Weiter Bernstein.
