# Jahr 3000 – Richtung D „Fünfziger-Zukunft“ (ROUND-2-CONTEXT, vom Besitzer gewählt, Dez. 2026)

Entstanden mit `bencium-innovative-ux-designer`: zehn Schrift-Entwürfe A–J, Besitzer: „d“. Jahr 3000 = Futurama-Welt, ohne Namen, Figuren,
Logos, Zitate, Originalschrift.

## Grundgedanke
Die Zukunft, wie man sie sich in den Fünfzigern vorgestellt hat: optimistisch, rund, pastellig – mit Schreibschrift wie auf alten Werbeschildern.

## Festgelegt
- Creme `#FBEBD1` (Flächen `#F6E1BF`), vier Tinten: Tinte `#2D3047` (Text, Gerichte), Orange `#C04A28` (Schreibschrift-Beschriftungen,
  Kochen, aktiver Reiter; gegenüber dem Entwurf `#E0603C` abgedunkelt für Lesbarkeit), Petrol `#1F7068` (Zahlen, Zeiten), Lila `#6B5CA5` (Kategorien).
- Jost 800 versal für Namen („Skin Zukunft“), Pacifico für Beschriftungen („Skin Schwung“), Systemschrift für Lesetext.
- Startseite `.j3Block` (`jahr3000.js`): Name + Datum, „Heute für dich“ (Schreibschrift), Gericht riesig (ohne Trennung, wird bei langen Wörtern
  kleiner), Untertitel, Zeit, „Kategorien“, vier größte Kategorien als große Petrol-Zahl + lila Name, „Alle n Rezepte“. 3D-Stadt unter Creme-Schleier.
- Keine Comic-Umrisse, harten Schatten oder Karten; Fotos mit runden Ecken. Kochmodus ebenso auf Creme.
